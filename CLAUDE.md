# CLAUDE.md

## Project notes vault

`docs/` is an Obsidian vault holding the project's notes. Start with `docs/STATE.md`.

- `docs/notes/` is the user's own notes: read it, never edit it.
- Files Claude writes get `author: claude` in frontmatter.
- Before finishing substantive work, update `docs/STATE.md` and add a `docs/sessions/YYYY-MM-DD-topic.md` entry.
- For code structure and file relationships read `docs/code/` (one note per module with classes, functions, imports and imported-by links). It is generated by `scripts/gen_code_notes.py` on every commit that touches `src/**/*.py` (pre-commit hook); never edit it by hand except the summary line between the `summary` markers in `_index.md` files.
- A Stop hook (`.claude/settings.json`) blocks finishing once if `src/` changed but `docs/STATE.md` did not.
- `CONTEXT.md` stays at the repo root (the domain-modeling skill expects it); `docs/Glossary.md` just points to it.
